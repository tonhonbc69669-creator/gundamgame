## 🌟 ฟังก์ชันหลักของ Gang Ai

- **โลโก้ & ชื่อแบรนด์ Gang Ai:** โดดเด่นในแถบนำทาง (Navbar) และส่วนท้าย (Footer)
- **เข้าเล่นได้ทันที:** ผู้เล่นคลิกที่ไอคอนการ์ดเกมส์ หรือปุ่ม "เล่นเกมส์นี้" เพื่อเปิดเล่นทันทีในแท็บใหม่
- **In-page Player:** มีปุ่ม "เล่นบนหน้านี้" สำหรับเล่นในกรอบหน้าต่างบนเว็บโดยไม่ต้องสลับแท็บ
- **Hero Carousel Banner:** แบนเนอร์สไลด์ไฮไลท์เกมส์เด่นขนาดใหญ่ด้านบน
- **ระบบค้นหา & ฟิลเตอร์แนวเกม:** รองรับหมวดหมู่ `Simulation`, `Strategy`, `RPG`, `Arcade`, `Party`, `Casual`, `Action`
- **ระบบแอดมิน (Admin Control):**
  - ล็อคอินด้วยรหัสผ่านแอดมินส่วนตัว (มีปุ่มเปลี่ยนรหัสผ่านได้ทันที)
  - เพิ่ม / แก้ไข / ลบ เกมส์ได้แบบเรียลไทม์
  - สำรองข้อมูล (Export JSON) และนำเข้า (Import JSON) ฐานข้อมูลเกมส์ได้ตลอดเวลา
- **ระบบความปลอดภัยและการป้องกัน AI ดูดข้อมูล (Security & Anti-Scraping Protection):**
  - `robots.txt` สกัดกั้น AI Bot และ Crawlers ทุกค่าย (GPTBot, ClaudeBot, CCBot, PerplexityBot, Bytespider ฯลฯ)
  - Meta Tags ป้องกัน AI (`noai`, `noimageai`) และประกาศลิขสิทธิ์
  - ป้องกันคลิกขวาดูดรูปภาพ (Disable Context Menu)
  - ป้องกันคีย์ลัดตรวจสอบโค้ดและแกะซอร์สโค้ด (F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S)
  - ป้องกันการ Drag & Drop ไฟล์ภาพไอคอนและแบนเนอร์ออกไปภายนอก
  - คอนโซลแจ้งเตือนระบบคุ้มครองทรัพย์สินทางปัญญาอัตโนมัติ
